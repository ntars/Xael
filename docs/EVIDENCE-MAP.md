# 证据强度对照表（Xael 5.0.0）

本表回答一句话：**这套算法里，每一条结论凭什么**。

「算法校正」这一轮的目标不是让结果好看，而是让每一句断语都能追到出处；追不到的，如实写「库外」「近世整理」「待考」，不拿通行说法冒充原书原文。

## 三档强度

| 档 | 含义 | 判据 |
|---|---|---|
| **A 原书直证** | 规则与断语都能在 `refs-texts/` 底本正文找到对应句子 | 由 `npm run check:cites`（篇名可回溯）与 `npm run check:readings`（断语逐子句可回溯）强制 |
| **B 结构自洽** | 底本给了结构关系（如七元递进 +4、三元九运），但绝对起点原书自云「不可得而考」 | 输出写明「结构自洽、锚点不可考」 |
| **C 库外/通行** | 库内 18 部无载，取近世整理或通行口诀 | 输出与文档明标「库外」「近世整理」「待考」 |

| 自检 | 管什么 | 现状 |
|---|---|---|

| ⑪ `check:readings` | 断语逐子句必须原样来自底本（防润色冒充原文） | 312 格 / 643 子句，0 条回不到底本 |

| `npm test` | 逐条口径断言 | 1389 项全过 |

## 一条判断原则

校正过程中反复遇到同一类岔路：**原书自相矛盾或语焉不详时，是把两说合成一句，还是并列摆出**。

选择后者，理由很实际——合成要靠加权折中，而权重没有出处，等于用自造数据掩盖真实分歧。所以本仓保留了大量「两说并存」「原文未言」「待考」的标注：岁运相冲的方向、毕法 5 条不判、德庆课天德月德、月忌日的历例与俗说、宿之吉凶、三诈五假、八宅等第、紫微四化。

**能站住的写清楚，站不住的也写清楚**——这比给出一句漂亮而查不到出处的话更有用。

**接入方式固定**：新底本放进 `refs-texts/` 并在文件头补齐五类元数据（朝代作者／公版依据／底本来源／用途／收录日期）→ `node tools/check-refs.mjs` 过 → 把引用写成《书名·篇名》→ `node tools/check-cites.mjs` 过 → 断语表接 `tools/check-readings.mjs` → `npm test` 与 `npm run check` 全绿才算升档完成。

也就是说：**升档不是改注释，是换证据**。改文档标注不算数，得让第 ⑨、⑪ 两项自检认账。
