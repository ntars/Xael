## 历法底座关键修复（支撑全部 17 项）

1. **节气三级精度**：VSOP87 截断级数（XL0 2666 项）+ 寿星锚点圈号（年内第 79 天锚 + round 圈号）+ ΔT 表；1901–2049 全部 3,576 个节气与参照「平均差 0 秒、p99 1 秒、最大 60 秒、日期全部相同」。
2. **旧年代朔表**：1985 年前朔改查寿星精密朔表（SHUO_KB 分段插值 + SB 日差修正），此前 Meeus 级数在 1901–1914 有 1–2 天朔差。
3. **跨日进位**：节气分钟进位与日期字段一致（1979 大寒跨日例）。

## 已声明的口径分歧（非缺陷，详见 docs/CALIBER-NOTES.md）

- 紫微四化「戊、壬」两干取中州主流表（可单表切换）。
- 紫微闰月：十五（含）以前归本月。
- 出生时刻恰在交节前后数分钟内的极端样本，受参照数据精度上限约束（实测 24,000 例未出现取值差）。
- 黄历「通例参考」「值星义理」为本项目自撰文案（旧版同位置亦为自撰），不参与对拍。
