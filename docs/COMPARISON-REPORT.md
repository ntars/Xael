# Xael 5.0.0 内核回归对拍报告（任务清单 17 项）

> **验收标准已变更（2026-10）**：本项目的算法正确性以**库内公版古籍原文**为准，
> 不再以「与任何既有实现逐字段一致」为验收标准。本报告记录的是**回归基线**——
> 证明重构后的内核在同口径下与参照实现等价、没有回归；凡文献有明文而参照实现
> 与之不合者，一律以文献为准改判，并在 `docs/CALIBER-NOTES.md` 的
> 「文献校正」节逐条记录改判与出处。因此下表中的「差异 0」表示**同口径等价**，
> 不表示本项目以参照实现为权威。

对拍基准：重构前的参照实现（其历法底座为 lunar-javascript 1.6.x、紫微底座为 iztro 2.6.2）。
对拍方式：同输入跑参照实现与新仓内核，逐字段比对，直至差异 0。对拍脚本为一次性工具，不随源码分发。
结论先行：**17 项任务全部归零**——在 1901–2100 全日期穷举对拍下，八字 876,588 例、大运 1,753,176 例、紫微 1,779,456 例、黄历/农历 73,049 天、奇门全家 876,588 例合计约 536 万例均为 0 差异（仅奇门定节 1 例受参照表进位影响，见文末）；全仓 1277 项断言、10 项发布自检全绿。

## 穷举边界已全部收敛

八字/大运/紫微/黄历/农历/八宅/飞星在 1901–2100 全日期穷举下均为 **0 差异**。
关键修正在于「交节时刻与出生时刻相等」的判定方向：参照实现在展示层把交节时刻
四舍五入到分，交节秒残差普遍为正，因此「出生时刻恰等于该分钟」实际仍在交节之前
（1995-07-07 22:00 小暑、1911-05-07 立夏等）。`jiePassed` 与 `prevJieqiAt /
nextJieqiAt` 统一改为「相等视为未交」（严格 `>` / `<`），并把秒位补零后比较字符串，
这一类差异全部消失（A 层 876,588 例、E 层 73,049 天双双归零）。
