# refs-texts/ —— 参考文献原书资料库

**用途**：存公版古籍的**原书原文**。算法依据有疑义时，翻这里查原文，不倒推、不转述。

**三条铁律**：
1. **只收原文**：正文为原书文字照录（仅规整空白行，不改一个字）；不做白话、不写解读、不由内核反推生成。
2. **只收公版**：明清及以前传本；民国著作须作者已过著作权保护期（如《子平真诠评注》徐乐吾）。
3. **不入发布包**：本目录不进小程序 / 网页 / uni-app 发布包，仅供仓库内查阅。

## 来源与校对状态（如实写）

- **底本来源**：殆知阁电子文本（GitHub `daizhigev20`，易藏/术数），2026-10-25 经 jsDelivr 下载。
- **校对状态：未精校**。电子文本难免录入讹误，对外引用或落算法前，请先核对影印本（四库本 / 通行刻本）。
- 个别底本自带排版符号（如《渊海子平》正文的星号分隔），按「原文照录不改字」原则保留。
- 收录时仅做四件事：统一换行、删除行尾空格、压缩连续空行、底本私用区占位字（殆知阁 OCR 缺字）统一转为缺字符号 □（三命通会 524 处、六壬大全 2 处、钦定协纪辨方书 316 处）。**文字一字未动**。
- 每部头部统一为六字段（标题/朝代作者/公版依据/底本来源/用途/收录日期）+ 分隔线；
  正文收束处标「（完）」；《钦定协纪辨方书》末页批注底本即断裂，已就地编辑注说明。
- 一致性由 `node tools/check-refs.py` 把关（头部字段、结尾标记、BOM/替换符/私用区/行尾空格全查）。
